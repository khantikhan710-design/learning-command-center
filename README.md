# 学习指挥台小程序

面向电子信息专业学习与考研复习的微信小程序：每日任务、专注计时、学习证据、分类收藏夹与艾宾浩斯复盘。

## 本地打开

1. 打开微信开发者工具，导入 `C:\Users\zly88\WeChatProjects\miniprogram-1`。
2. 确认 AppID 为 `wx8bd6738ab0f497da`。
3. 点击“编译”或按 `Ctrl + R`。

云开发环境已配置为 `study-command-doc-d4ddzc7244fd32`。项目不会提交本机私有开发者工具配置。

## 当前功能

- 今日任务：自选时长、左滑置顶/删除/分类。
- 专注：番茄倒计时、临时离开记录。
- 学习记录：自定义分类、图片/PDF/Word 附件、记录左滑管理。
- 复盘：艾宾浩斯节奏、已掌握归档/取消掌握、离线“举一反三”。
