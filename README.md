# 学习指挥台 · 1.2.0

面向电子信息专业学习与考研复习的个人微信小程序。它把每日任务、番茄专注、学习资料卡、艾宾浩斯复盘和月度归档放在同一条学习闭环中。

## 1.2 功能

- **今日**：任务新增、时长、完成分区、左滑置顶/分类/删除、长按排序、每日学习卡、每日目标和今日总结。
- **专注**：原生风格倒计时、关联科目/任务、严格专注离开记录、后台恢复与重置。
- **记录**：自定义分类、Goodnotes/WPS/纸质资料导入指引、图片/PDF/Word、复制文字、转为复盘、收藏夹管理；附件失败时如实标记“原件未保存”，可重选或删除。
- **复盘**：1/2/4/7/15/30 天节奏、到期提醒、已掌握归档/恢复、离线举一反三。
- **归档**：月度文件夹、Obsidian 文本导出、七天专注看板、完整本机备份与恢复。
- **本周复盘**：近 7 天任务完成率、科目投入、连续复习和到期薄弱知识点汇总。
- **检索**：资料卡和复盘收藏夹均支持关键词、分类、来源、月份筛选。
- **提醒与知识来源**：今日页本机到期复习入口；归档页显示微信订阅消息的真实配置状态、公开电路课程与个人教材资料的学习来源目录。

## 数据说明

当前版本以本机数据为准。云开发环境 `study-command-doc-d4ddzc7244fd32` 已在代码中配置，但需完成云函数部署与官方授权后才能启用跨设备同步。

- 云端可用时：图片和文件上传到云存储。
- 云端不可用时：图片、PDF、Word 会尝试保存到当前手机的小程序本机文件空间；只有成功后才显示为可打开附件。
- 小程序本机文件空间总量约 10MB。大 PDF/Word 或空间不足时，资料卡可保留正文和“原件未保存”提示，但不会假装文件已经保存。
- Goodnotes、WPS 不向小程序开放内部资料读取权限。请先把原件导出/分享至微信文件传输助手，再在资料卡中按来源提示选择文件；原始文件应继续保存在 Goodnotes、WPS 或自己的网盘中。
- 完整备份 JSON 保存任务、记录、复盘和索引；原始本机附件仍建议保留在 WPS、Goodnotes 或自己的网盘中。
