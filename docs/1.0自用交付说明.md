- 定位：个人学习管理工具，不依赖云端也能完成日常任务、专注、记录、复盘和归档。

## 现在如何使用

### 电脑开发时实时看到更新

1. 用微信开发者工具打开项目。
2. 保存代码后，项目私有配置已经启用热编译；模拟器会自动更新。
3. 页面没有刷新时按 `Ctrl + R`。

### 在本人手机上使用

1. 开发者工具点顶部“预览”。
2. 用注册该小程序的本人微信扫码。
3. 首次使用先在“今日”添加任务；在“归档”点一次“复制完整备份”，粘贴到 Obsidian 或私人笔记中保存。

### 以后更新手机里的版本

1. 修改完成后先在开发者工具编译并真机预览。
2. 点击顶部“上传”，版本号按 `1.0.1`、`1.0.2` 递增，备注写本次变化。
3. 到小程序后台的开发版本，将新版本设为体验版；本人作为管理员或体验成员即可使用新版本。

预览二维码适合即时测试；长期个人使用更适合上传后设为体验版。

## 数据安全边界

- 任务、专注、记录和复盘默认保存在当前设备的小程序本地存储。
- 云端未授权时，图片和 PDF/Word 会保存到当前手机的本机文件空间，能在资料卡中打开或转发。
- “复制完整备份”导出的 JSON 用于恢复文字数据、任务、复盘和附件索引；不包含附件二进制文件。
- 不要卸载微信、清理小程序存储或更换手机后才想备份；建议每周复制一次完整备份，并保留原始 Goodnotes/WPS 文件。

## 当前不承诺的能力

- 云端授权未恢复前，不支持跨 iPad/手机/电脑自动同步。
- 小程序不能锁住手机、拦截其他 App，也不能把倒计时放到系统状态栏。
- 不读取 Goodnotes、WPS、欧几里得或不背单词的内部数据；资料卡提供人工归档入口。
