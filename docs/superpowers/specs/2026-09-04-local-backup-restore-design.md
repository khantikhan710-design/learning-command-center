# 本地备份与恢复 Design

## Goal

在云同步不可用时，让用户将本机学习数据复制为完整 JSON 备份，并在同一或另一台设备恢复。

## Scope

- 备份任务、任务分类、学习记录、记录分类、复盘、复盘分类、累计专注分钟和学习日期。
- 备份文本带格式标识、版本和导出时间。
- 归档页顶部提供“复制完整备份”和“恢复备份”。
- 恢复前显示条目数量并二次确认；确认后覆盖上述本机数据并刷新归档。

## Data and safety

- 备份只保存在用户剪贴板/自行保存的位置，不上传任何服务。
- 非法 JSON、格式不匹配或缺少数据会拒绝恢复，不修改现有数据。
- 恢复明确是覆盖而不是合并，避免同一任务被重复导入。
- 图片和文件只保存当前记录里已有的标识或文件信息；未上传到云端的临时附件无法备份。

## Testing

纯工具模块测试：生成包含版本和日期的 JSON、正常解析与统计、拒绝损坏或非本项目备份。
