# 学习闭环完善版设计

## 目标

让学习指挥台在不依赖云权限、其他 App 接口或系统级权限的条件下，可靠完成“今天做什么 → 专注多久 → 复习什么 → 看见进步”的本地学习闭环。

## 研究依据

- 开源学习看板通常把任务、番茄专注和轻量统计放进同一条流程，而非分散的工具集合。
- 间隔复习工具把今天到期、连续学习和未来负担放在首屏，避免用户在多个页面找下一步。
- 采用本地优先：数据先写入设备，云端可用时再同步，避免权限问题阻断核心学习。

参考：
- https://github.com/remoshan/smart-student-productivity-dashboard
- https://github.com/Cletrix-Labs/study-revision-planner

## 范围

### 1. 可靠专注计时

专注开始后持久化绝对结束时间，而非只依赖前台 `setInterval`。小程序从后台返回时以当前时间重新计算剩余时间；时间已到则只结算一次专注记录。小程序无法提供系统悬浮窗或后台闹钟，因此 UI 明确提示该限制。

### 2. 今日下一步

今日页增加一个不增加输入负担的“下一步建议”卡：优先展示到期复盘；否则展示第一项未完成任务；若都没有则提示可以补充任务或做资料整理。卡片同时显示目标、已完成专注、任务预计总时长与差额。

### 3. 一致的数据解释

所有页面继续使用同一套任务分类。归档看板解释近七天实际专注；今日页解释计划总时长与实际专注的差异；复盘页展示到期条目与当前记忆节点。

### 4. 统一页面排版

保持现有蓝色学习主题，统一标题层级、卡片留白、说明文字和主操作位置。删除重复的空提示，优先把“下一步动作”放在用户打开页面后可见的位置。

## 不在范围内

- 系统悬浮窗、锁机、通知栏实时秒数。
- 自动读取或写入 Goodnotes、WPS、欧几里得、不背单词的数据。
- 云开发权限修复与跨设备自动同步。

## 验收

1. 计时开始后，按结束时间计算，返回页面时显示真实剩余时间，且过期仅结算一次。
2. 今日页能在有到期复盘、仅有任务、无任务三种状态下给出单一下一步建议。
3. 计划分钟、已专注分钟与差额均有确定来源且被自动化测试覆盖。
4. 所有现有测试及新增测试通过，未修改 `project.config.json`。
