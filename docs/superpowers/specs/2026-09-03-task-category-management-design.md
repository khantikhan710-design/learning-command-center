# 今日任务分类管理设计

## 目标

将今日任务中的固定“自定义”选项改为真正可创建、重命名和删除的分类，且不丢失已有任务。

## 使用流程

1. 用户左滑一张今日任务卡，点击“分类”。
2. 页面展示当前可选分类，并提供“＋ 新建分类”和“管理分类”。
3. 新建分类时，用户输入名称；名称去除首尾空格后不得为空或与现有分类重名。创建成功后，当前任务立即使用该分类。
4. 管理分类时，用户选择任意分类，随后可重命名或删除。
5. 重命名后，所有使用该分类的任务同步更新为新名称。
6. 删除前必须显示二次确认。确认删除后，该分类从列表移除；使用它的任务保留，分类改为“未分类”。

## 分类与兼容规则

- 初始分类为：考研数学、专业基础、硬件电路、英语、AI 学习。
- 所有分类均可重命名和删除，包括初始分类。
- “未分类”是任务没有分类时的显示状态，不属于可管理分类列表。
- 新增任务的初始分类为“未分类”。
- 旧任务的“自定义”分类在读取时规范化为“未分类”。
- 分类列表允许为空；空列表时用户仍可通过“＋ 新建分类”创建分类。

## 数据保存

- 分类列表存入本机存储键 `studyTaskCategories`。
- 任务继续存入 `studyTasks`，分类变更直接更新每项任务的 `subject`。
- 任务快照保存到云端时，分类列表与任务一并保存，确保跨设备恢复后保持一致。
- 云端请求失败不得阻止本机任务操作。

## 错误处理

- 空分类名：提示“分类名称不能为空”。
- 重名：提示“已有同名分类”。
- 删除：明确提示“分类下的任务将变为未分类，任务内容不会删除”。

## 测试

- 新建合法分类会被保存且可立即分配给任务。
- 空名称与重复名称不能新增。
- 重命名会更新分类列表及全部关联任务。
- 删除会移除分类并将关联任务转为“未分类”。
- 旧“自定义”任务读取后会显示为“未分类”。
