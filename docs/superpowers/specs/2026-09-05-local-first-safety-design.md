# 本机优先与数据安全设计

## 目标

在云开发暂不可用时，让学习指挥台明确运行在本机模式，仍能安全记录、导出、恢复和复盘数据；任何云端或附件失败都不能伪装为保存成功。

## 范围

- 在今日页和归档页显示云同步状态，并提供一次真实云连接检测。
- 备份支持生成 JSON 文件、调用微信文件转发能力、从微信文件中导入并先预览再恢复；不支持时保留复制 JSON 的降级路径。
- 归档资料卡可进行删除、置顶、转为复盘、按来源筛选，所有删除均二次确认。
- 安全看板显示上次备份间隔、未保存原件附件数量、超过 10MB 的附件风险。
- Goodnotes/WPS 导入后按来源预填资料卡标题、来源和日期；用户仍需从微信文件选择器选择自己导出的文件。
- 周复盘增加可复制的“投入、完成率、薄弱点、下周第一步”文字报告。

## 关键原则

1. 本机写入先完成，再尝试云同步；云失败只更新状态，不能回滚本机数据。
2. 文件只有本机路径或云文件 ID 时才显示“可打开”；否则明确显示“原件未保存”。
3. 云连接检测调用现有 `studyData` 云函数；成功才显示“云同步可用”。
4. 恢复备份永远先预览，并经二次确认覆盖本机数据。

## 验收

- 云函数失败时，界面显示“本机模式”，本机任务和记录仍可保存。
- 用户可选择生成的 JSON 备份文件并恢复数据。
- 安全看板能从真实本机数据统计附件风险。
- 周复盘报告可复制到剪贴板。
