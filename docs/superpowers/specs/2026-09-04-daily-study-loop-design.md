# 每日学习闭环设计

## 目标

把“今日任务、专注时长、间隔复习”汇总成当天能立即行动的闭环，不增加页面，也不依赖云开发权限。

## 方案选择

采用轻量提醒卡，而不是新增日程系统或要求用户给每项任务设置日期：

- 在“今日”已完成任务下方显示当天收尾卡。
- 收尾卡展示任务完成数、专注进度和今日到期复盘数，并提供“复制今日总结”。
- 在“复盘”页面顶部显示今天应复习的条目，原有分类收藏夹仍完整保留。

这样保留现有的自由任务方式，同时把用户每天最需要查看的下一步集中起来。

## 数据与规则

- 复盘条目沿用现有 `next` 字段（格式为 `YYYY/M/D`）。
- “今日待复习”指未掌握且 `next` 不晚于本地当天的条目；没有 `next` 或日期不合法的旧条目不计入提醒。
- 每日总结只读取本地已有的 `studyTasks`、`focusMinutes`、`dailyGoalMinutes` 和 `reviewItems`，不写入新数据。
- 复制文本包含日期、已完成任务数、专注分钟与目标、待复习条目数；若有待复习条目，附带最多三条简短内容，避免剪贴板过长。

## 界面与交互

### 今日

已完成任务区块之后增加“今日收尾”卡：

- 三项数据：任务、专注、待复习。
- 待复习大于零时显示“去复盘”按钮，跳转至现有复盘标签页。
- “复制今日总结”将纯文本复制到剪贴板，并用轻提示确认。

### 复盘

标题下方、输入区之前增加“今天该复习”卡：

- 没有到期项目时显示“今天没有到期复盘”。
- 有到期项目时显示最多三条，内容可直接查看；每条的“复习完成”沿用现有间隔复习动作。
- 超过三条时显示剩余数量提示，完整清单仍可在下方原分类中展开查看。

## 边界与错误处理

- 该功能完全离线可用；云同步失败不影响统计、提醒或复制。
- 不修改历史复盘日期，不自动标记任何条目完成。
- 所有时间都以设备本地日期计算，避免 GMT/CST 文本进入界面。

## 验证

- 工具函数测试覆盖：到期、未来、已掌握、无效日期，以及每日总结文本。
- 页面接入后运行现有全部 Node 测试与 JavaScript 语法检查。
