# 学习指挥台 1.2：复盘、检索、提醒与知识来源设计

## 目标

在不依赖当前不可用的云开发权限的前提下，让小程序形成可验证的本机学习闭环：

1. 每周能看懂时间投入、计划完成和需要回看的知识点；
2. 记录与复盘能按科目、来源、月份、关键词找到；
3. 复盘到期有明确的本机提示，并为未来的微信订阅消息保留真实的配置入口；
4. 电路、高数、英语和硬件资料有可追溯的学习来源，而不是复制未经授权的教材全文。

## 不做的事

- 不下载、抓取、缓存或展示未授权教材的整本内容。
- 不在 CloudBase 仍返回 `-601034` 时声称数据已经云端同步或可定时推送。
- 不新增第六个底部 Tab；继续保留“今日、专注、记录、复盘、归档”五页结构。
- 不承诺与 Goodnotes、WPS、不背单词或欧几里得自动双向同步；它们没有为本项目提供已验证的可用接口。

## 信息架构

### 归档页：新增「本周复盘」

置于月度归档前方，默认统计最近 7 个自然日，包含：

- **计划完成率**：最近 7 日创建的任务中，具有 `completedAt` 且完成时间落在本周期的任务比例；没有可统计任务时显示“从本周新增任务开始累计”。
- **科目投入**：从 `focusSessions` 聚合每个 `subject` / `taskTitle` 的专注分钟数，展示总时长、占比以及柱状图；未归属的会归为“未分类”。
- **薄弱知识点**：从未掌握且已到期的 `reviewItems` 聚合 `type`。排序规则是：到期数量优先，其次是待复盘总数；显示“建议先复盘”的明确说明，不伪装为 AI 结论。
- **连续学习**：复用现有学习活跃日期，以近七天连续天数显示鼓励提示。

统计只读本机数据；CloudBase 恢复后仍可在现有 local-first 同步层读取云端快照，但页面不依赖云端才可工作。

### 记录页、复盘页：各自增加检索条

两页均增加同样的轻量检索控件：

- 关键词：匹配标题、正文、附件名、来源标签或复盘内容；
- 科目 / 分类：使用用户现有的可编辑分类；
- 来源：记录页使用 Goodnotes、WPS、纸质扫描等实际来源标签；复盘页显示其资料卡来源或“手动录入”；
- 月份：根据 `date`、`created`、`masteredAt` 解析为 `YYYY-MM`，并兼容此前中文本地时间格式。

筛选结果保留文件夹折叠、置顶、删除、复制和复盘跳转；无结果时给出“清空筛选”操作。筛选本身不改变原始数据。

### 复习提醒：真实能力分层

1. **本机提醒（1.2 可交付）**：每次进入今日页或复盘页时计算已到期项目；首页显示数量与下一项，并能一键进入复盘。连续多天未复盘时也生成提示文案。
2. **订阅授权入口（1.2 可交付）**：设置卡明确显示“需要配置微信订阅消息模板与云端定时任务”。没有模板 ID 时不调用空的订阅 API，也不显示“已开启”。
3. **微信定时推送（后续条件完成后开启）**：用户在公众号后台选择合法订阅消息模板，提供模板 ID；CloudBase 与小程序授权恢复，部署云函数/定时触发器后，才调用订阅消息接口。用户每次授权的结果会真实显示为接受、拒绝或未配置。

### 开放学习来源目录

在归档页的本周复盘下提供小型「知识来源」卡片，内容是章节纲要、来源名称、版权/使用提示和复制链接，不内嵌第三方网站。

初始目录：

| 学习线 | 内容结构 | 可用来源方式 |
| --- | --- | --- |
| 电路 | 基本定律、等效与网络、动态电路、正弦稳态、频响、二端口 | 西电公开课程课件/作业链接；用户自有教材与笔记的上传资料卡 |
| 硬件/模电 | 器件、放大、反馈、运放、功放、电源、原理图与调试 | 高校公开课与用户资料卡 |
| 高数 | 极限连续、一元微积分、多元微积分、级数、常微分方程、数一题型 | 国内教材章节索引（默认同济体系）与用户自有教材页/笔记 |
| 英语 | 真题词汇、外刊生词、词根词缀、错词回顾 | 用户导入的词表、自己的外刊摘记和公开可用词表 |

西电公开《电路分析基础》资源可以作为电路章节索引的首个链接。教材名称只作为参考框架；只有用户上传或明确可公开的材料才进入可搜索、可复盘内容。

## 数据与兼容策略

- 继续使用 `studyTasks`、`studyRecords`、`reviewItems`、`focusSessions` 等本地键，不迁移或删除用户已有数据。
- 任务完成时已保存 `completedAt`；新周统计据此计算，旧任务无时间则不强行归入历史周。
- 新增的筛选状态是页面瞬态状态，不写入备份，不污染资料或复盘数据。
- 新增来源目录是程序内静态元数据；用户资料仍以 `studyRecords` 为唯一事实来源。
- 现有云端保存失败必须保留本机成功路径；相关异常只记控制台，不阻断页面操作。

## 验收标准

1. 有本周数据时，归档页能正确显示 7 日科目分钟、完成率和薄弱分类；无数据时显示可理解的空状态。
2. 对记录和复盘，任意关键词、分类、来源、月份的组合筛选都不损坏折叠/删除/置顶/复制操作。
3. 今日页有真实的到期复盘入口；订阅卡未配置时明确说明，不宣称消息会推送。
4. 知识来源目录可复制链接，且不会把教材全文保存进本机或云端。
5. 全部既有测试保持通过，并新增周复盘、检索过滤、提醒状态与来源目录的纯函数测试。
