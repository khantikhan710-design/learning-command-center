# 学习可视化看板与遗忘曲线设计

## 目标

修复专注页分类来源，并将已有的本地专注、任务和复盘数据转为易读的学习看板。

## 分类一致性

- 今日任务唯一分类来源为本地键 `studyTaskCategories`。
- 专注页改为读取同一键；选择科目后，该轮专注会记录对应分类快照。
- 为保护旧任务和分类改名后的历史，专注选择器还会合并未完成任务中已有但不在分类列表的科目名称。

## 专注图表：归档页

不引入 ECharts 或云端依赖，使用小程序原生视图绘制：

1. **近 7 日专注柱状图**：横轴为近七天日期，纵向柱高代表每天专注分钟；顶部显示本周期最高分钟数，便于快速判断哪天最稳定。
2. **本周分类投入**：每个今日任务分类一条水平进度条，长度为该分类本周专注时间占比。
3. **本周项目投入**：具体任务也按相同方式排列；无具体任务的专注不混入项目条。

统计默认显示本周（周一至周日），仅统计已经自然完成的专注轮次。没有数据时显示明确空状态，不伪造图表。

## 艾宾浩斯遗忘曲线：复盘页

- 基于现有间隔 `1、2、4、7、15、30` 天，绘制一条原生 Canvas 的 30 天记忆保持率示意曲线。
- 曲线有六个复习节点；已经经过的阶段为实心蓝点，当前待复习阶段为橙色点，未来节点为浅色点。
- 以最早到期、否则最早将到期的未掌握条目作为当前展示对象，卡片显示其分类、当前第几次复习和下次日期。
- 没有未掌握条目时，不画虚假曲线，提示先加入一条复盘内容。

曲线用于解释“为什么此刻该复习”，实际排程仍由当前稳定的间隔复习逻辑负责，不会因画图改变用户数据。

## 参考与取舍

开源学习工具普遍将“连续性 / 未来工作量 / 分类统计”放在同一看板中；例如 [RemNote Statistics Plugin](https://github.com/Justtolook/RemNote-Statistics-Plugin) 提供活动热力图、未来到期预测和范围筛选，[Recall](https://github.com/Garuda8887/recall) 把遗忘曲线、复习历史、分类条形统计合并为一个复习视图。这里保留其中最适合个人手机学习的部分，避免复杂筛选和外部服务。

## 验证

- 纯工具测试验证分类合并、近七日时间桶、分类/项目汇总、曲线节点阶段。
- 现有全量 Node 测试和页面 JavaScript 语法检查必须通过。
- 手动验证：今日新增分类后，专注页立即可选；完成一轮后，归档图表随之增加；复盘页在有未掌握条目时显示对应节点。
