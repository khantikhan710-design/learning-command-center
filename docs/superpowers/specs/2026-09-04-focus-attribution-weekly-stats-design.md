# 专注归属与周统计 Design

## Goal

让用户在开始专注时可选地标记科目和今日任务，并在归档页看到本周真实的专注投入。选择不是必填，避免为了统计打断开始学习。

## Interaction

- 专注页增加“本轮归属”卡片：科目下拉选择和具体任务下拉选择。
- 默认科目为“未分类”，任务为“不关联具体任务”；直接点开始仍按现有逻辑工作。
- 选择某项任务时，自动带出其科目；用户仍可只选择科目。
- 每轮自然完成时保存一条本机专注会话：分钟、结束时间、严格模式、科目、任务 ID 与任务标题。
- 暂停不计入会话；旧的累计专注分钟继续保留。
- 归档页顶部增加“本周专注”：本周总分钟、按科目汇总、按任务汇总。
- 本统计从本版本开始精确记录；过去只有累计分钟，不能反推到具体科目。

## Data and safety

- 本机键为 focusSessions；每条会话不可因后来改名/删除任务而丢失，因为同时保留 taskTitle 和 subject 快照。
- 云端可用时继续调用既有 focus session 写入；云端失败不影响本机统计。
- 周按本地周一 00:00 到周日 23:59 计算。

## Testing

- 纯工具测试覆盖：周界限、跨周过滤、科目与任务汇总、未分类、删除任务后的历史会话。
- 开发者工具手工验证：默认直接开始、选科目、选任务自动带科目、完成后归档统计更新。
