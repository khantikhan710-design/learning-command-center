# 今日任务操作与临时离开摘要

## 目标

让用户能安全管理误添的今日任务，并在严格专注结束一次临时离开后看到实际用时。

## 任务卡滑动操作

- 用户在“今日任务”中向左滑动一张任务卡，露出三个操作：置顶、分类、删除。
- 一次只展开一张任务卡；点击空白区域或展开另一张卡时收起之前的操作。
- 置顶：切换置顶状态。置顶任务始终排在非置顶任务前，其他任务保持原有顺序。
- 分类：弹出分类选择器，选项为考研数学、专业基础、硬件电路、英语、AI 学习、自定义。
- 删除：弹出二次确认；确认后从本地任务列表移除，取消则保留。
- 任务时长、完成状态与现有新增任务能力保持不变。

## 临时离开摘要

- 开启严格专注且主专注已开始时，退出小程序会消耗一次离开机会，并暂停主专注。
- 返回小程序时，临时离开立刻结束，剩余时间作废。
- 页面显示“本次临时离开：已用 X 分 X 秒”。
- 摘要在下一次临时离开开始前一直保留，不影响三次机会、主专注暂停或手动继续的既有规则。

## 数据与错误处理

- 所有新增字段保存在既有 `studyTasks` 本地存储中：`pinned`、`subject`。
- 删除必须经确认，避免误触。
- 滑动距离不足时不触发操作区，保持点击完成任务和设置时长可用。
- 该阶段仍为本地版，不涉及云同步。

## 验证

- 自动测试覆盖：置顶排序、分类更新、删除确认状态、临时离开用时格式化。
- 开发者工具手动验证：滑出操作、取消删除、确认删除、分类后刷新、返回小程序后的离开摘要。
