# 今日优先级与学习内容卡设计

## 目标

让今日任务的排列真实表达用户优先级，并让首页标题提供短小、可靠、贴合电子信息学习的内容，而不是空泛口号。

## 排序交互

- 长按未完成任务后，上下拖动。
- 拖入另一张普通任务卡时，页面即时交换顺序；松手时才写入本机和云端。
- 置顶任务仍高于普通任务；它们可在置顶组内排序，普通任务也可在普通组内排序。
- 已完成任务不参与排序，避免重新安排历史。

## 每日内容卡

- 每天按日期稳定轮换一条本地内容，无需联网。
- 两种内容平衡出现：学习思想摘要，以及 AI/嵌入式/硬件协同的论文要点。
- 文学/哲学内容用“思想摘要”而非捏造原文；论文内容用不超过两句的中文改写并展示来源标识。
- 首批技术来源：arXiv 2410.07265（LLM 软硬件协同）、arXiv 2503.06027（端侧 AI）、MLArchSys/ISCA 2025（能效推理）。

## 验收

1. 纯排序工具可移动任务，且只重写相同置顶状态的未完成任务顺序。
2. 每日内容工具同一天输出稳定，能循环输出多种内容。
3. 今日页展示长按提示与来源卡，不新增导航页或网络依赖。
