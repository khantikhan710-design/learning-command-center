# 个性化复习教练设计

## 目标

让复盘页面和今日收尾卡根据真实复习状态给出可行动的提示，而不只是显示到期条目数量。

## 状态来源

- 新增本地 `reviewActiveDates`：用户点击“复习完成”或“掌握”时记录设备当天日期。
- 原有 `reviewItems` 提供未掌握条目数和到期条目数。
- 日期记录会加入已有本地备份，恢复备份后连续复习统计也随之恢复。

从此功能上线开始才会积累复习连续天数；旧复盘条目不会伪造历史复习记录。

## 教练阶段

| 情况 | 标题 | 建议 |
| --- | --- | --- |
| 没有复盘内容 | 从第一条开始 | 添加一条错题或概念，建立自己的复习队列。 |
| 今天已复习 1 天 | 第 1 天 | 今天先完成一条，先把节奏建立起来。 |
| 今天已连续 2–3 天 | 节奏已建立 | 连续复习 N 天，优先完成今天到期内容。 |
| 今天已连续 4 天以上 | 记忆在加固 | 连续复习 N 天，保持小步稳定即可。 |
| 昨天复习、今天尚未复习 | 别让节奏断掉 | 完成一条即可续上连续天数。 |
| 已漏 1 天或更多 | 重新衔接 | 已间隔 N 天，今天先处理最早到期的一条，不补量。 |
| 到期条目 4 条及以上 | 先清积压 | 有 N 条待复习，先完成最早三条，再做新内容。 |

当“积压”与“断档”同时出现时，优先展示积压提示，但正文保留断档后的低压力建议。

## 界面

- “复盘”页的“今天该复习”卡顶部增加教练标题和一句建议。
- “今日收尾”卡增加同一条简短建议，避免两页内容互相矛盾。
- 不创建新标签页，不要求用户填写额外表单。

## 边界

- 仅使用本地日期，避免 GMT/CST 文本。
- 多次点击同一天的复习只记录一次。
- 云同步失败不影响教练提示；日期轨迹和复盘数据仍本地可用。

## 验证

- 用纯工具函数测试开始、连续、今天未复习、漏一天、多天断档、积压、同日去重。
- 本地备份测试覆盖 `reviewActiveDates` 的导出与旧备份兼容。
